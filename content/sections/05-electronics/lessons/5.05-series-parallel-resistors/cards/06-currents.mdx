exam_fact: In a parallel circuit the total current is the sum of the branch currents. Every branch has the same voltage, so the branch with half the resistance carries twice the current.
---
Every branch of a parallel circuit sees the **same voltage**, the battery's. Each branch takes its own current (I = E ÷ R), and the battery supplies them all:

**I(total) = I1 + I2 + I3 + …**

If resistor A carries **twice** the current of resistor B with the same voltage across both, A must have **half** the resistance of B.
