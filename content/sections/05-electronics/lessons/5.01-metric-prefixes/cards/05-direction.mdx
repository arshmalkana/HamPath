type: concept
title: Smaller unit, bigger number
teaches:
  - B-005-001-001
  - B-005-001-007
  - B-005-001-010
exam_fact: Going to a smaller unit makes the number bigger (×1000 per step); going to a bigger unit makes it smaller (÷1000 per step).
---
The amount never changes, only the label.

- **MHz → kHz** is one step down, so multiply by 1000: 3.525 MHz = **3 525 kHz**.
- **kHz → MHz** is one step up, so divide by 1000: 7040 kHz = **7.040 MHz**.
- **MHz → GHz** is one step up: **divide by 1 000**.

A quick check: there are more small units in the same amount, so the number with the smaller unit is always the bigger number.
