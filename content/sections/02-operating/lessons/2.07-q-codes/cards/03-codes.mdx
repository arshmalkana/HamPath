| Code | Meaning |
| --- | --- |
| QRS | Send more slowly |
| QTH | My location is… |
| QRL? | Is this frequency in use? (send before transmitting on CW) |
| QSY | Change frequency |
| QSB | Your signal is fading |
| QRZ? | Who is calling me? |
| QRM | I'm being interfered with |
| QRN | I'm troubled by static |
| QRX | I will call you again |
