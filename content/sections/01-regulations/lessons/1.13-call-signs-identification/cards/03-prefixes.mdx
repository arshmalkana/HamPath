Canadian amateur call signs normally start with **VA, VE, VO or VY**, then a digit for the region, then the suffix: **VA3RAC**, for example.

| Prefix | Region |
| --- | --- |
| VE1 / VA1 | Nova Scotia |
| VE2 / VA2 | Quebec |
| VE3 / VA3 | Ontario |
| VE7 / VA7 | British Columbia |
| VO1 / VO2 | Newfoundland / Labrador |
| VY0 / VY1 / VY2 | Nunavut / Yukon / PEI |

You identify with your **call sign**, not a nickname, name or location. (K, W, N and A are American; G, M and EA are European.)
