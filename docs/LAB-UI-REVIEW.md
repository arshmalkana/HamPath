# Lab UI review

Every lab-step card (188 of them, covering every mode of all 35 labs) was opened on a production build at desktop width (1280 px) and phone width (390 px). Each was checked two ways:

- **Automated geometry checks** in the page:
  - SVG labels overlapping each other or running outside their drawing;
  - "NaN", "undefined" or "Infinity" anywhere in the text;
  - content wider than the lab panel;
  - controls sitting on top of each other.
- **Visual review** of contact sheets: every screenshot tiled 16 to a sheet, read for anything that looked off.

## What was wrong, and the fixes

## Verification

- The automated checks went from **39 findings to 6** on the re-run, and those 6 were item 15, which was then fixed.
- A contact sheet of the 20 affected labs was checked again by eye.
- Every lab smoke test (all 9 sections) still reaches its goals with no page errors.
- All 365 unit and API tests pass.

The review scripts (`labui.mjs` for screenshots and geometry, `sheet.mjs` for contact sheets) are Playwright drivers run against a production build. Re-run them after any large lab change.
